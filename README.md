# Bio3D v3.4 Android PWA

Esta versión prepara Bio3D para una experiencia instalable en Android mediante PWA.

## Incluye
- Manifest Android/PWA optimizado.
- Iconos 192 y 512.
- Modo standalone.
- Botón de instalación.
- Detección de aplicación ya instalada.
- Service Worker y caché offline heredados de v3.3.
- Guía `ANDROID_INSTALL.md`.

## Requisito
Para que Chrome ofrezca instalación, Bio3D debe servirse desde HTTPS (o localhost durante desarrollo). El ZIP no es un APK.
