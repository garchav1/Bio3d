# Bio3D v3.1 Stable — Inicio rápido

## Abrir correctamente
Bio3D usa módulos web, por lo que se recomienda ejecutarlo mediante un servidor HTTP local.

### Windows / macOS / Linux
1. Descomprime la carpeta.
2. Abre una terminal dentro de `Bio3D_v3.1_Stable`.
3. Ejecuta:
   `python -m http.server 8080`
4. Abre en el navegador:
   `http://localhost:8080`

## Primera comprobación
1. Pulsa **Ejecutar diagnóstico**.
2. Comprueba el modelo 3D.
3. Cambia una vista multicapa.
4. Inicia un recorrido.
5. Responde un quiz.
6. Prueba Modo Profesor.
7. Exporta un respaldo.

## Móvil
Para probar en Android, sirve la aplicación desde un equipo de la misma red local y abre la dirección IP local del equipo desde Chrome. Las funciones de micrófono/voz pueden requerir permisos y un contexto seguro según el navegador.

## Nota
“Stable” indica que el paquete supera las comprobaciones estáticas incluidas. La validación definitiva de voz, GPU, táctil y uso en clase depende del dispositivo y navegador reales.
