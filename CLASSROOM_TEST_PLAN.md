# Bio3D v3.1 RC — Plan de prueba en aula

## Antes de la clase
1. Abrir Bio3D mediante un servidor HTTP local.
2. Ejecutar el diagnóstico.
3. Confirmar que el cuerpo 3D aparece y responde al giro/zoom.
4. Probar el modo rendimiento en un teléfono.
5. Crear un respaldo de datos.

## Prueba del estudiante
1. Introducir nombre.
2. Elegir Secundaria o Universidad.
3. Abrir un sistema anatómico.
4. Completar un recorrido.
5. Responder al menos 3 preguntas.
6. Confirmar puntos y progreso.

## Prueba del profesor
1. Activar Modo Profesor.
2. Crear una lección y un objetivo.
3. Iniciar la lección.
4. Marcarla completada.
5. Revisar historial.
6. Exportar CSV.

## Prueba técnica
- Cambiar entre capas.
- Probar órganos, músculos, nervios y sistema urinario.
- Probar voz si el navegador la admite.
- Exportar respaldo JSON.
- Recargar Bio3D.
- Importar el respaldo.
- Confirmar recuperación del progreso.

## Criterio de RC
La aplicación puede utilizarse en una prueba controlada cuando las siete comprobaciones del panel “Prueba para aula” han sido verificadas manualmente en el dispositivo que se usará.
